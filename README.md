# Sanjaya Electricals & Civil Contractors

Single-page Next.js website based on the supplied business card.

## Run locally

```bash
npm install
npm run dev
```

Then open:

http://localhost:3000

## Main files

- `app/page.tsx` — website content
- `app/globals.css` — design and responsive styling
- `components/Logo.tsx` — recreated logo
- `app/layout.tsx` — browser title and SEO metadata

## CTAs

- Call Now uses the phone number.
- WhatsApp opens a new WhatsApp conversation with a pre-filled enquiry.
- Get a Quote opens the visitor's email application with a pre-filled quote request.

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Vercel will detect Next.js automatically.
4. Add `sanjayaelectricals.com` under Vercel → Project Settings → Domains.
